# 生死狙击工具箱（SSJJ Toolbox）

面向《生死狙击》（4399 / Wooduan 微端）的绿色免安装桌面工具箱，**核心主打武器皮肤与建模本地替换**，并附带可选的大厅资源本地加速、帧率设置与常用维护工具。

> **当前本地便携包**：`release/生死工具箱1.2.0.zip`。解压后双击 `生死狙击工具箱.exe` 即可运行，无需安装 Python 或 .NET 环境。单文件修正版见 `release/生死狙击工具箱-1.2.0-修正版.exe`。

---

## 核心功能：武器皮肤与建模替换（主推）

- **全量武器与皮肤内置清单**：内置 1200+ 武器与 470+ 皮肤数据（`weapon_catalog.json`），支持按分类筛选与关键词搜索，无需联网拉取清单。
- **皮肤 + 建模 + 开镜 + 音效联动**：
  - 支持单改皮肤、单改目标建模，或「建模 + 目标皮肤」组合替换；
  - 自动处理双阵营后缀（`_ct` / `_t`）映射，确保不同阵营外观一致；
  - 切换目标建模时，开镜准星与开火/换弹/切枪音效同步跟随目标武器。
- **不修改游戏原始资源包**：所有外观替换仅在局内生效，不改动游戏原资产文件，停用后下一局即恢复原样。
- **冷加载低开销**：默认进局应用一次规则即完成，不留常驻轮询线程，不影响局内帧率。
- **退出自动还原**：局内退出前自动还原状态并等待收尾，减少退出回大厅时的异常。

### 三步上手

1. 解压便携包，双击 `生死狙击工具箱.exe`（弹出管理员确认点「是」）。
2. 在首页**「一键启动」**页：选原武器 → 选目标建模/皮肤 → 添加或直接点启动（工具箱会自动拉起官方启动器，在游戏窗口内登录选区即可；已有大厅时自动沿用当前会话）。
3. 停用换肤：在侧栏**「换肤注入」**页点击关闭/移除，下次进局恢复原样。

## 次要功能（全部默认关闭，按需开启）

### 1. 本地资源加速（可选）
将大厅常用静态资源（活动页、背包、仓库、武器图标等）缓存到本地，减少重复加载转圈：
- **默认关闭**：不会自动改写 `hosts` 或写入大体积缓存；
- 需要时在侧栏**「本地加速」**页使用统一开关启停，关闭时自动清理守护进程并还原 `hosts`；
- 游戏更新接口与版本检测保持直连官方源，避免因缓存导致更新异常。

### 2. 自动维护与便携体验
- **跨盘符自动识别游戏目录**：自动探测默认路径、注册表、卸载项、桌面快捷方式及各盘符，发给其他电脑也能直接识别。
- **启动自动清理垃圾**：每次打开工具箱时，在后台静默清理过期崩溃转储（`hangdumps\*.dmp`）及无窗口残留的 `MicroClient.exe`，避免锁死大厅缓存或占用 C 盘空间。
- **单实例保护**：重复打开工具箱时自动清理同目录旧窗口实例，防止后台多开冲突。
- **只读目录兼容**：放在只读目录或 U 盘时，配置与日志自动落盘到 `%LOCALAPPDATA%\ssjj-toolbox\`。

## 目录结构

```text
toolbox/
  ssjj_toolbox.py      PySide6 图形界面主入口（单实例锁 + 启动自动清理）
  backend.py           前端与各功能模块的桥接层
  oneclick.py          一键换肤规则管理与启动编排
  quick_login.py       官方启动器 / 微端探测与无参数安全拉起
  skin_swap.py         武器/皮肤清单加载与规则读写
  ui/                  深色主题与各功能页面（一键启动、换肤、本地加速、工具等）
risk/
  payload/             C# 战斗端外观替换与退出保护模块（WeaponSwapper / ExitGuard / Loader）
  proxy/               本地加载通道源码与构建脚本
  guard.py             后台状态守护与日志管理
  mitm.py              可选本地加速 HTTPS/HTTP 代理模块
local_cdn.py           大厅资源本地缓存与回源服务
ssjj_paths.py          游戏安装路径自动探测与公共路径
weapon_catalog.json    内置武器与皮肤目录
build_exe.py           PyInstaller 单文件与绿色便携包打包脚本
```

## 从源码打包

环境要求：Windows 10/11 x64、Python 3.12（安装 `PySide6`、`psutil`、`cryptography`、`pyinstaller`、`UnityPy`、`Pillow`）。

```bash
# 仅打包到 dist\
python build_exe.py

# 生成 release\生死工具箱<当前版本>.zip
python build_exe.py --release
```

## 日志与排障

运行日志统一存放在 `%LOCALAPPDATA%\ssjj-toolbox\`：
- `risk_inject.log`：局内换肤/建模/准星/音效命中记录
- `risk_mode.log`：守护状态与本地加速日志
- `housekeeping.log`：每次启动的自动清理记录
- `launch.log`：游戏启动过程记录

卸载方式：先在工具箱内关闭/移除换肤与加速，然后直接删除工具箱文件夹即可，不写系统服务。
